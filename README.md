# Financial AI Co-Pilot

Local-first deterministic financial intelligence system for Private Equity analysis.

## Core Principle

The model is a router and formatter, not a calculator.
All arithmetic, period handling, unit normalization, SQL retrieval, and validation are deterministic Python.

## Detailed Run Guide

This section is the practical runbook for local setup and usage.

### 1. Prerequisites

- Python 3.10+
- Windows PowerShell (or any shell)
- Internet access only if you want optional cloud planner mode

### 2. Clone and enter project

```bash
git clone <your-repo-url>
cd financial_analyst
```

### 3. Create virtual environment

Windows:

```bash
python -m venv project\venv
project\venv\Scripts\activate
```

macOS/Linux:

```bash
python -m venv project/venv
source project/venv/bin/activate
```

### 4. Install dependencies

```bash
cd project
pip install -r requirements.txt
```

### 5. Put files for ingestion

Drop your structured files into:

- `project/input_files/`

Supported structured formats:

- `.csv`
- `.xlsx`
- `.xls`

Qualitative formats supported by Phase 2 pipeline:

- `.pdf`
- `.docx`

### 6. Run ingestion pipeline (CLI)

From `project/`:

```bash
python Data_Ingestion/pipeline.py
```

Useful modes:

```bash
python Data_Ingestion/pipeline.py --mock
python Data_Ingestion/pipeline.py --report-only
python Data_Ingestion/pipeline.py --skip-qualitative
```

What this does:

1. Reads structured files from `input_files/`
2. Detects entities, units, periods, and layout
3. Writes staging facts
4. Runs conflict resolution + validation + onboarding gate
5. Promotes to `live_facts`
6. Runs qualitative pipeline unless `--skip-qualitative` is used

### 7. Run Streamlit app

From `project/`:

```bash
streamlit run app.py
```

App capabilities now:

- Structured upload queue
- Background ingestion workers
- Job status panel
- Entity LIVE-state visibility
- Deterministic tool tabs:
  - metric fetch
  - variance
  - ratio
  - source lineage
  - context search
- Free-text deterministic router tab

### 8. Optional cloud planner mode (Phase 4 skeleton)

Cloud planning is optional and disabled by default.

Set env vars before running app/pipeline process:

Windows PowerShell:

```powershell
$env:ORCH_CLOUD_ROUTER_ENABLED="1"
$env:ORCH_LLM_API_URL="https://<provider-endpoint>"
$env:ORCH_LLM_API_KEY="<api-key>"
$env:ORCH_LLM_MODEL="gpt-4o-mini"
```

Behavior:

- Cloud planner returns a strict JSON tool plan.
- Plan is validated against whitelist/arg rules.
- Only deterministic Phase 3 tools are executed.
- On any cloud/planner error, routing falls back to local deterministic logic.

### 9. Run tests

From repo root:

```bash
project\venv\Scripts\python.exe -m pytest project/Data_Ingestion/test_phase3_phase4.py -q
project\venv\Scripts\python.exe -m pytest project/Data_Ingestion/test_phase4_cloud_plan_validation.py -q
project\venv\Scripts\python.exe -m pytest project/Data_Ingestion/test_file_reader_hardening.py -q
project\venv\Scripts\python.exe -m pytest project/Data_Ingestion/test_qualitative.py -q
```

### 10. Verify DB location

Active DB:

- `project/Data_Ingestion/financial_agent.duckdb`

### 11. Reset local DB (if needed)

Windows:

```powershell
Remove-Item project\Data_Ingestion\financial_agent.duckdb
```

Then re-run pipeline.

### 12. Common troubleshooting

1. `No module named pytest`
   - Use the venv interpreter explicitly:
   - `project\venv\Scripts\python.exe -m pytest ...`

2. Files ingest but entity not queryable
   - Ensure source file state reached `LIVE`
   - Re-run pipeline and complete conflict/onboarding prompts

3. Cloud planner mode fails
   - Confirm all `ORCH_*` env vars are set
   - Check endpoint compatibility with chat-completions style response
   - System auto-falls back to local deterministic routing

4. Mixed-unit anomalies
   - Row-level unit heuristics are improved but still not perfect in all legacy sheets
   - Use source lineage tab (`list_sources`) to verify critical metrics

## Safety Constraints

1. No LLM arithmetic
2. No raw SQL generated by LLM
3. Query only LIVE-state facts
4. Reconcile conflicts before answering
5. Keep raw financial data local
